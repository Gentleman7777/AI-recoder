# Названия по содержанию и собеседники

- Добавлены контекстные названия из Ollama вместе с резюме, отдельное поле `title`, поиск по названию и скачивание аудио с этим названием.
- Добавлено локальное определение разных голосов через sherpa-onnx, временные метки Whisper и сопоставление слов с голосами.
- Реплики показываются с цветными метками собеседников и кнопками перехода к нужному моменту аудио; копирование сохраняет метки.
- Аудио поддерживает HTTP Range для перемотки. При сбое разделения голосов текст остаётся доступным.
- Добавлены установка моделей, настройки, проверки сохранения реплик при повторе резюме, изоляции аккаунтов и просроченных обработчиков.

# Регистрация и отдельные библиотеки

- Добавлена открытая регистрация по уникальному имени и паролю, отдельные сессии и библиотеки пользователей.
- Владельца записи определяет сервер. Чужие записи, аудио, результаты, удаление и обработка возвращают 404; списки и статистика ограничены текущим пользователем.
- Старый аккаунт и его данные переносятся автоматически. Записи без владельца не достаются первому посетителю из интернета: их может забрать только первый прямой локальный аккаунт.
- Черновики разделены по аккаунтам; прежние черновики переносятся старому владельцу. При смене аккаунта вкладки скрывают старые данные и останавливают воспроизведение.
- Незавершённые запросы привязаны к аккаунту, с которым начались; отправка после смены сессии отклоняется.
- Добавлены интеграционные тесты изоляции двух пользователей, миграции, сохранения сессий и защиты от повторного восстановления отозванных токенов. В браузере проверены регистрация, загрузка, чужая ссылка, смена аккаунтов, запись и 10 проверок черновиков.

# Личный аккаунт и вход

- Добавлен единственный аккаунт владельца: создание на localhost, вход с других устройств и выход из текущей сессии.
- Все маршруты API, включая прямое прослушивание и скачивание аудио, защищены серверной проверкой сессии.
- Пароли хешируются bcrypt, случайные сессии хранятся в PostgreSQL в виде хешей, действуют 14 дней и переживают перезапуск.
- Добавлены защита изменяющих запросов от чужого источника, ограничение попыток входа и безопасные cookie для HTTPS.
- Добавлен адаптивный светлый экран входа; при выходе данные убираются из интерфейса.
- Проверены жизненный цикл сессии, защита API и создание аккаунта, включая браузерный стенд с отдельной схемой PostgreSQL.

# Более простой светлый интерфейс

- Зелёная палитра заменена холодными светлыми поверхностями и фиолетовым акцентом; обновлены логотип, значки и визуализация голоса.
- Убраны технические настройки, названия моделей, сведения о сервере и базе, размеры и расширения в списке записей. Вместо настроек добавлена краткая справка.
- Упрощены главная, карточка записи, уведомления и ошибки. Внутренние сообщения API больше не выводятся пользователю.
- Проверены пять ширин экрана и запись синтетического аудио с сохранением на изолированном стенде.

# Ускорение создания резюме

- По умолчанию отключены рассуждения Ollama/Qwen3, добавлен предел генерации и отдельный компактный формат для коротких заметок.
- Настраиваются `OLLAMA_THINK`, `OLLAMA_MAX_TOKENS` и `OLLAMA_KEEP_ALIVE`; менять рабочий `.env` для применения новых значений по умолчанию не требуется.
- В журнале показываются время распознавания/резюме и отдельные затраты Ollama на загрузку, обработку запроса и генерацию.
- Добавлены проверки ограничений генерации, обработки усечённого ответа и явных настроек модели; добавлен замер на синтетической расшифровке.

# Светлый интерфейс

- Полностью обновлены главная, библиотека, страница расшифровки, настройки и диалоги: светлый фон, зелёный акцент, простая навигация и единая типографика.
- На главной оставлены запись, импорт, компактная статистика и последние аудиозаписи; убраны повторяющиеся рекламные блоки.
- Убрано дублирование метаданных на странице аудио; справка по воспроизведению сворачивается.
- Обновлены визуализация записи, логотип, значки PWA и цвет панели браузера.
- Добавлен воспроизводимый генератор PWA-значков: `scripts/generate-icons.ps1`.

# Надёжность записи и обработки

- Добавлена постоянная очередь PostgreSQL с ограниченным числом обработчиков, блокировками с продлением и восстановлением после перезапуска. Повторные запросы не создают параллельные задачи одной записи.
- Расшифровка сохраняется сразу после Whisper; сбой Ollama не уничтожает текст и больше не считается успешным завершением. Добавлен отдельный повтор создания резюме и проверка структуры ответа модели.
- Черновики микрофонной записи сохраняются фрагментами в IndexedDB, восстанавливаются после перезагрузки и защищены от одновременного открытия в поддерживающих Web Locks браузерах.
- Добавлено прямое скачивание записанного аудио и сохранение названия при повторной попытке загрузки.
- Интерфейс показывает этап обработки и готовую расшифровку до завершения анализа. Исправлено обновление этапов и защита от устаревших ответов при переходе между записями.
- Добавлены интеграционные тесты очереди и обработки, проверки ответов Ollama и изолированный браузерный стенд.

# Изменения в версии Echo PWA

- Встроен адаптивный веб-интерфейс в Go-сервер через `embed.FS`.
- Реализованы обзор, библиотека, поиск по последним 100 записям, фильтры, детализация, визуальная запись с микрофона, загрузка аудио, просмотр результатов.
- Добавлены PWA-манифест, иконки 192/512 и service worker только для статических файлов; приватные API-ответы не кешируются.
- `GET /api/stats` для сводной статистики.
- `DELETE /api/recordings/{id}` для удаления записи и результатов.
- `GET /api/recordings/{id}/audio` теперь отдаёт аудио `inline` для плеера; `?download=1` скачивает оригинал.
- Перед распознаванием аудио нормализуется через FFmpeg до 16 kHz mono WAV (новый `FFMPEG_CLI`, по умолчанию `ffmpeg`).
- Удаляются временные текстовые файлы Whisper после обработки.
- Дополнены HTTP-заголовки безопасности и инструкции по Cloudflare Access.

**Пока не сделано:** Cloudflare Tunnel, серверная авторизация, распознавание говорящих. Не открывайте Go API публично без защиты.
