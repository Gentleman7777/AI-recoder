# Проверка авторизации

Реализован личный аккаунт одного владельца. Пароль задаёт пользователь при первом локальном открытии приложения. Публичной регистрации, восстановления по почте и отдельных библиотек нескольких пользователей нет.

## Серверные проверки

`go test ./... -count=1 -timeout 120s` прошёл с `TEST_DATABASE_URL`, включая реальные проверки PostgreSQL. Каждый тест использовал отдельную схему `echo_test_*`, которая удалена при завершении; рабочие таблицы не использовались. `go vet ./...` прошёл.

Проверены:

- Запрет чтения записей, статистики, результатов и аудио без сессии, а также защита будущих API-маршрутов.
- Ограничение первичной настройки прямым loopback-подключением; запрет настройки через публичный Host или forwarding-заголовки.
- CSRF: обязательный заголовок изменяющих запросов, проверка Origin, запрет удаления с другого источника даже с действующей сессией.
- Лимит 10 попыток в минуту, в том числе при конкурентных запросах, и его истечение.
- Хеширование пароля и токена, запрет перезаписи существующего владельца, проверка неправильного пароля.
- Сохранение сессии при создании нового экземпляра middleware, ротация при повторном входе, отзыв после выхода и истечение срока действия.
- HttpOnly, SameSite=Strict; отдельная Secure cookie с префиксом __Host- на публичном HTTPS-адресе.

## Браузер

Проверен настоящий Go middleware через opt-in `TestBrowserPreview` с отдельной временной схемой PostgreSQL и пустым тестовым API записей:

- Создание тестового аккаунта, проверка несовпадения паролей, автоматический вход.
- Обновление страницы сохраняет вход.
- Выход скрывает пространство и очищает форму.
- Неверный пароль показывает понятную ошибку, правильный повторно открывает приложение.
- Главная с кнопкой выхода и экран входа на ширинах 320, 390 и 1440 px не имеют горизонтального переполнения.
- Снимки `auth-desktop.png` и `auth-mobile.png` сохранены с пустыми полями.

Проверки синтаксиса `web/auth.js`, `web/app.js` и `tests/web-server.cjs` прошли. Браузерный стенд корректно завершён через защищённый тестовый маршрут; схема удалена. Тестовые маршруты отсутствуют в обычном сервере. Рабочий `.env`, пароль владельца и рабочие записи не менялись. Учётная запись создана только в тестовой схеме.

Для использования: перезапустить Go-приложение, открыть localhost:8080 на его компьютере и задать собственное имя/пароль. Перед внешним доступом завершить локальную настройку; публичный адрес должен использовать HTTPS, прокси должен сохранять Host.
