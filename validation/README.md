# Проверка доработок — 16 октября 2026

Проверки завершены успешно:

- `go test ./... -count=1 -timeout 120s` с реальной локальной PostgreSQL через `TEST_DATABASE_URL`. Для каждого интеграционного теста использовалась отдельная уникальная схема, удалённая после теста. Рабочие таблицы не изменялись.
- `go vet ./...`.
- `node --check` для `web/app.js`, `web/drafts.js`, `web/sw.js` и `tests/web-server.cjs`.
- Конкурентные запросы к HTTP API: 12 запросов создают одно задание.
- Конкурентная очередь: 20 запросов на постановку создают одно задание; 20 попыток захвата дают одного владельца.
- Истечение блокировки и новый владелец после имитации аварии; устаревший владелец не может сохранить текст, завершить задачу или изменить её статус.
- Сохранённая расшифровка видна до ответа Ollama. Ошибка HTTP 503 оставляет текст доступным; отдельный повтор резюме не запускает распознавание заново.
- Контрольная точка после распознавания, совместимость повторной миграции, восстановление задач старой версии и очистка очереди при удалении записи.
- Штатная остановка обработчика возвращает прерванное задание в очередь.
- В браузере: запись синтетического звука, пауза, продолжение, остановка, изменение названия, закрытие окна, перезагрузка, восстановление аудио и названия. У восстановленного плеера `readyState=4`, ошибки декодирования нет.
- Успешная отправка восстановленного аудио в изолированный тестовый API очищает черновик; кнопка обработки доступна сразу после сохранения.
- Восемь браузерных проверок IndexedDB: порядок фрагментов, метаданные, изоляция записей, откат транзакции при дубликате, получение блокировки, отказ второму владельцу, скрытие отправленных черновиков и удаление тестовых данных.

Браузерный стенд работал на `localhost:18080` с синтетическим звуком и тестовыми API-ответами. Настоящий микрофон, Whisper и Ollama при этих проверках не запускались. Рабочий `.env` не менялся. Тестовый сервер остановлен после проверки.
